# HR Analytics Power BI Dashboard

## Project Overview
This Power BI project analyzes HR employee data to understand employee count, attrition, department-wise performance, gender distribution, salary trends, and other HR insights.

## Tools Used
- Power BI
- Microsoft Excel
- DAX
- Data Cleaning
- Data Visualization

## Dataset
The dataset used in this project is an HR employee dataset in Excel format.

## Dashboard Features
- Total Employees
- Male and Female Employee Count
- Department-wise Employee Analysis
- Attrition Analysis
- Salary Analysis
- Age Group Analysis
- Job Role Analysis
- Interactive Filters and Slicers

## Files Included
- HR Analytics Dashboard.pbix
- hr-data-analysis.xlsx
- Dashboard screenshots

## Key Insights
- Identified employee distribution by department
- Analyzed attrition trends
- Compared gender-wise employee count
- Created interactive dashboard for HR decision-making

## How to Use
1. Download the `.pbix` file.
2. Open it in Power BI Desktop.
3. Refresh the dataset if required.
4. Explore the dashboard using filters and slicers.
